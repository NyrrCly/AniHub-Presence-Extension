This project is an unofficial fan-made creation and is **not affiliated** with the AniHub administration or developers.

We take your data from:
1. **[anihub.in.ua](https://anihub.in.ua/)** - AniHub
2. **ashdi.vip** - Anime player in anihub
3. **fenixplay.xyz** - Anime player in anihub
4. **moonanime.art** - Anime player in anihub
5. **localhost:3000** - Server created by [AniHub-Presence-Server](https://github.com/NyrrCly/AniHub-Presence-Server)

### How to use

1. Download latest extension version from [releases](https://github.com/NyrrCly/AniHub-Presence-Extension/releases).
2. Add extension to your FireFox.
3. Download latest server version from [another repository](https://github.com/NyrrCly/AniHub-Presence-Extension/releases).
4. Run .exe file.

Just watch anime, and the activity will work!
